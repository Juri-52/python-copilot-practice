# 作業メモ

## 原因

`CartItem.subtotal()` が商品価格だけを返しており、購入数量を計算に使っていませんでした。

そのため、りんごを2個追加しても200円、牛乳を3個追加しても250円となり、合計が450円になっていました。

## 修正内容

- `cart_item.py`
  - 小計を `商品価格 × 数量` で計算するように修正しました。
- `cart.py`
  - `Cart.add_item()` で数量が1以上の整数か検証するようにしました。
  - `0`、負の数、浮動小数点数、文字列、`None`、`True`、`False` は拒否します。
  - 不正な数量の場合は、次の例外を発生させます。
    - `ValueError("数量は1以上の整数にしてください")`
  - 検証を明細追加前に行うため、不正な追加ではカートの内容を変更しません。
- `tests/test_cart.py`
  - 不正な数量の検証テストを追加しました。
  - 同じ商品を複数回追加し、別明細として保持しつつ合計できることを確認するテストを追加しました。

`products.json` と既存テストの期待値は変更していません。

## 実行結果

プロジェクトの仮想環境を使用して、以下を実行しました。

```text
python -m pytest -q
```

結果:

```text

```
